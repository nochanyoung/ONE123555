# 웹사이트(청년 주거지원 실부담 계산기) 실행 방법

## 준비물

- [Node.js](https://nodejs.org) 설치 (한 번만)

## 실행 순서

1. 저장소 내려받기 (이미 있다면 `git pull`만)

   ```bash
   git clone https://github.com/nochanyoung/ONE123555.git
   cd ONE123555/docs/웹사이트/safe-bet
   ```

2. 의존성 설치 (한 번만, 또는 `package.json`이 바뀌었을 때)

   ```bash
   npm install
   ```

3. 실행

   ```bash
   npm run dev
   ```

4. 브라우저에서 접속

   ```
   http://localhost:3000
   ```

## 끌 때

`npm run dev`를 실행한 터미널 창에서 **Ctrl+C**
