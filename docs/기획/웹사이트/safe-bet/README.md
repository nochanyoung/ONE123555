# 🏠 청년 주거지원 실부담 계산기

주거비·계약 조건을 입력하면, 받을 수 있는 주거지원 정책을 자동으로 판정하고 최종 예상 주거비를 계산해주는 웹앱입니다.

> 멋쟁이사자처럼 Campus AX-Ton 프로젝트. 기획 배경은 [기획 문서](../../2026-08-10-youth-housing-prd.md), 세부 요구사항은 [기능요구사항 체크리스트](../../2026-08-19-기능요구사항-체크리스트.md)를 참고하세요.

## 화면 구성

```
/            계약 조건 입력 (F1)
/eligibility 정책 자격 판정용 조건부 질문 (F2)
/result      규칙 기반 판정 결과 + 신청 링크 (F3, F4)
```

## 실행하기

```bash
npm install
npm run dev
```

브라우저에서 **http://localhost:3000** 을 엽니다.

## 테스트

판정 규칙(`lib/eligibility.ts`, `lib/combinations.ts` 등)은 결정론적 규칙 기반이라 단위 테스트로 검증합니다.

```bash
npm test
```

## 환경변수

API 키 등 민감한 값은 `.env.local`에 저장하며 git에 커밋하지 않습니다 (`.env.local.example` 참고).

실행 중 문제가 생기면 [웹사이트-실행방법.md](../../../웹사이트-실행방법.md)를, 코드 수정 전에는 [코드 수정시 유의사항.md](../../../코드%20수정시%20유의사항.md)를 참고하세요.
