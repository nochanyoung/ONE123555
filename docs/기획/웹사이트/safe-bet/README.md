# 🏠 청년 주거지원 실부담 계산기

익산시 신동 원룸 계약을 앞둔 청년을 위한 웹앱입니다. 매물 조건을 입력하면 정책 지원금을 반영한 실제 예상 주거비를 계산해줍니다.

> 멋쟁이사자처럼 Campus AX-Ton 프로젝트. 기획 배경과 전체 로드맵은 [기획 문서](../../기획/2026-08-10-youth-housing-prd.md)를 참고하세요.

## 실행하기

```bash
npm install
npm run dev
```

브라우저에서 **http://localhost:3000** 을 엽니다.

실행 중 문제가 생기면 [웹사이트-실행방법.md](../웹사이트-실행방법.md)를 참고하세요.
